# 每周学习时段建议设计

**状态：待用户审阅；未批准前不实现。**

## 目标与背景

SISU 学习计划目前保存课程、注册、考试与里程碑，以及截止日期；Moodle/手动任务也有截止时间，课表则提供固定上课时段。学生需要把这些事项转成日常可执行的学习安排。本功能根据现有本地数据推荐学习时段，用户确认后才保存；不连接 SISU 私人认证、不新增后端，也不自动修改课程、作业或计划事项。

## 已确认的用户目标与约束

- 优先改善学习负荷与时间规划。
- 由应用自动推荐空闲时段，用户确认后才加入计划。
- 默认只在每天 **08:00–22:00** 安排，周末可用。
- 本地优先；不得覆盖用户已有课程或任务。

## 建议的 MVP 范围

1. **推荐输入**：未完成且截止时间有效的 SISU 计划项、未完成且有截止时间的任务、课表课程。仅把未来 7 天内有明确截止时间的计划项/任务作为待安排事项；不根据无截止日期课程凭空推断负荷。
2. **冲突来源**：所有课表课程（含手动课）及已确认的学习时段。课程在时段内即视为冲突；不修改课程。
3. **时间粒度与工作量假设**：建议以 60 分钟学习块为单位，每块之间预留至少 15 分钟空档；一个事项每天最多推荐一个块。缺少耗时数据时不声称估计完成总工作量，显示为单次专注块；用户可跳过建议。截止更近的事项优先；同一截止日期按计划项/任务原始稳定顺序排序。
4. **推荐范围**：滚动未来 7 个本地日，每日 08:00–22:00；只推荐开始时间晚于当前时刻的块。搜索从事项截止日之前向前放置，优先较早且不冲突的空档；找不到合适空档的事项明确列入“本周无可用时段”，不能伪造成功。
5. **用户确认**：建议先以待确认卡片展示标题、来源、建议时段和截止时间。逐项“加入计划”或全部确认均可；取消/跳过只影响当前建议，不写入数据。已确认的学习块本地持久化并计入下一次冲突检测。确认不会自动标记原任务/计划项完成。
6. **数据与界面归属**：学习块由 `lib/` 的纯数据模型/策略拥有，存于独立 `localStorage` 键（通过 `lib/storage.ts` 注册）；学习计划 hook 负责生成与确认，`SisuStudyPlan.tsx` 只呈现并派发操作。既有任务和 SISU 计划项的 schema 不做破坏性迁移。
7. **提醒与日历显示不纳入 MVP**：已确认的块在 SISU 学习计划区中显示与可删除；本版不伪装成课表课程、不改变 Moodle dueAt/startAt 语义、不发系统通知。后续可以单独设计提醒或课表视图联动。
8. **过期与重复处理**：每次生成时排除完成、过期、无效日期事项；同一来源事项已有未删除的确认块时不再生成重复建议。用户删除确认块后可重新生成。

## 用户可见验收标准

- 有课表冲突时，任何建议学习块都不与课程时间重叠，且前后学习块至少间隔 15 分钟。
- 每个建议块完整落在本地日期 08:00–22:00 窗口内，未来七天范围包含周末。
- 已过期、已完成、无截止日期或日期非法的事项不生成建议；截止日相同结果稳定可复现。
- 无空档时显示明确的不可安排事项，不丢失它们，也不生成重叠块。
- 推荐仅为建议；未确认不得持久化。确认后重启仍可见；重新生成不得重复安排同一事项；用户删除后重新生成可再次出现。
- 确认、删除学习块不改变原课程、作业完成状态、Moodle 提交状态、SISU 计划完成状态或通知已读状态。
- 纯函数测试覆盖空数据、课程冲突、连续课程/15 分钟缓冲、跨日、周末、截止优先、已完成/过期过滤、无可用空间、重复建议、持久化与确认隔离；组件测试覆盖待确认、确认、跳过、删除与重挂载。
- 完成实现后运行项目门禁：`npx tsc -b --pretty false`、`npx vitest run`、`npm run test:consistent`、`npx oxlint`、`npm run build`。界面改动还须按项目工作手册在当前本地桌面/模拟器上实测，不以单独构建代替行为验证。

## 数据形状建议

新建 `StudyBlock`：`id`、`sourceKind: 'task' | 'sisu-plan'`、`sourceId`、`title`、可选 `courseCode`、`startAt`、`endAt`、`createdAt`。推荐结果与已确认块分开：推荐由纯函数即时推导、不落盘；仅确认操作写入持久化集合。若实现审查发现已有数据契约能更简单且不改变语义，可在计划中提出等价调整，再交用户审阅。

## 设计取舍

- **推荐使用本地明确截止日期与课表数据**，而非云端学习分析：无需新服务、凭据或外传数据；代价是没有截止日期/耗时估算的事项不做“完整学习负荷”承诺。
- **确认后作为独立学习块保存**，而非伪装成课表课程或普通任务：避免污染 SISU/ICS 同步和 Moodle 状态语义；代价是 MVP 中学习块仅在学习计划区显示，不进入周课表或系统提醒。
- **单次 60 分钟专注块**是可解释的默认建议，而非耗时预测；用户可确认、跳过或重新规划。将来如果需要个性化时长/可用时间，需另行设计偏好设置。

## 自审记录

- **占位符/未决事项**：没有 TBD。确认的单块 60 分钟、15 分钟间隔、未来 7 天、每日 08:00–22:00、截止优先及无通知/无周视图均已明确。
- **一致性**：建议不写盘，确认才持久化；删除后重新生成可再次推荐；已确认块参与冲突检测，规则相互一致。
- **范围**：单一子系统，集中在学习计划 UI 与本地纯函数，不包括通知、周课表、用户作息配置、外部服务或课程工作量估算。
- **隐含输入检查**：无时区时使用设备本地日期；跨日课表事件按完整时间区间计算；非法时间和零长度课程必须忽略；当天已过时间不得推荐；课程跨越可用时间窗会占据其相交部分；同一事项多来源关联不自动合并，身份键按来源类型与来源 ID 精确区分。
